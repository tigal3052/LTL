읽기 포인트 현재 노드와 미래 ? 체인의 관계
시각 원칙 전투 HUD보다 경로 비교를 먼저 읽기
  • 선택 상태: 현재 live choice 중 하나가 강조된다.
  • 표현 방식: 수치보다 구조, 액션보다 경로 해석을 우선한다.
  • 보조 영역: 선택 후 상세는 참조용이고 항상 열려 있는 전투 도크가 아니다.

번호 주석

wireframe annotations
  1. 1

    런과 스테이지는 서로 다른 진행 신호다

    Run 1/5 는 전체 여정의 큰 축이고, Stage 6/25 는 현재 노드 흐름의 위치 신호로 따로 읽히게 한다.

  2. 2

    다섯 개의 live choice 가 한 비교 라인에 있다

    선택지 A부터 E까지를 동일한 카드 구조로 나란히 배치해, 스캔 순서와 비교 판단이 흔들리지 않게 한다.

  3. 3

    미래 노드는 ? 체인으로 의도적으로 축약된다

    다가오지 않은 구간은 세부를 숨기고 물음표 흐름으로만 남겨, 현재 선택이 만드는 경로 감각만 전달한다.

  4. 4

    백팩은 전투 도크가 아니라 참조 / 로드아웃 표면이다

    항상 열린 전투 HUD 느낌을 피하고, 필요 시 읽는 보조 표면으로 배치해 노드 선택 화면의 본질을 유지한다.

의도

이 페이지는 경로를 읽는 보드다. 선택지 비교가 먼저 보이고, 전투성 정보는 노출하지 않는다.

한국어 라벨은 실제 UI에서 바로 읽히는 수준으로 유지하고, 영어는 제목과 구조 태그에만 사용해 문서형 와이어프레임의 의도를 분명히 한다.
