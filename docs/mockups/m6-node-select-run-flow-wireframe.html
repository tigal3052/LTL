이 화면은 제목과 전체 로드맵 이미지만으로 현재 스테이지 구조를 읽게 만든다. `Stage 3/5` 예시이므로 시작, 지나온 노드, 현재 5선택, 남은 노드, 보스전의 다섯 레벨이 모두 보이며, 미래 노드는 회색 `?`, 지나온 노드는 당시 선택했던 지형의 색을 그대로 남긴다.

번호 주석

map-first annotations
  1. `Stage 3/5` 예시에서는 정확히 5개 레벨만 보이게 구성한다: 보스전, 남은 노드, 현재 5선택, 지나온 노드, 시작 노드.
  2. 남은 노드는 회색처리만 하지 않고 원 안에 `?`를 넣어 “아직 정체가 드러나지 않은 단계”임을 즉시 읽게 만든다.
  3. 현재 선택 가능한 노드는 다섯 개를 병렬 배치하되, 정보는 숨기고 색상 차이만으로 읽게 만든다.
  4. 지나온 노드는 실제 선택했던 지형의 색을 기억하고, 다색 지형은 반반으로 분할해 당시의 선택 흔적이 남도록 만든다.
