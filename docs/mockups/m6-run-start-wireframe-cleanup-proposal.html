  1. 상단 제목은 `캐릭터 선택`으로 교체하고 설명 문장은 제거합니다.
  2. 설정 버튼을 우측 상단으로 끌어올려 현재 빈 구석을 살립니다.

  6. CTA는 버튼만 남기고 높이를 줄여, 위쪽 선택 UI가 더 많은 공간을 쓰게 합니다.
