Artifact Codex Direction Study

책을 펼친 도감 UI 시안 비교

`ItemBook.png`를 기반으로, 기존 타일·핀 자산의 작은 블록 질감을 유지하면서 좌측 상세 페이지와 우측 수집 그리드를 연결하는 3가지 고급 방향을 정리했습니다.

추천 기준
  • 실제 일러스트 파일이 나중에 들어와도 레이아웃이 무너지지 않을 것
  • 기존 픽셀 자산과 톤이 어긋나지 않을 것
  • 도감 선택과 상세 읽기가 한눈에 이어질 것
Recommended

A. Illustrated Folio

좌측을 큰 일러스트 중심의 전시 페이지로, 우측을 수집 카드 그리드로 구성한 구조입니다. 가장 “도감답고”, 이후 실제 아트 도입에도 가장 잘 버팁니다.

그래픽 방향
일러스트는 크게, 선택 카드는 기존 타일 질감으로 작은 블록성을 유지합니다.
확장성
실제 PNG 컷아웃만 교체하면 좌측 대표 이미지와 우측 카드 썸네일 둘 다 즉시 대응됩니다.
Trade-offs
  • 장점: 도감다운 전시감이 가장 강하고, 실제 아트 도입 가치가 가장 크게 살아납니다.
  • 장점: 좌측 정보 계층이 자연스럽고, 선택된 아이템이 명확하게 강조됩니다.
  • 주의: 좌측 대표 아트 영역이 큰 만큼 placeholder 품질도 일정 수준 이상으로 챙겨야 합니다.
Approach B

B. Archivist Ledger

좌측을 일러스트보다 기록 카드와 수치 정보 중심으로 구성한 방식입니다. 정리감은 좋지만, 시각 임팩트는 다소 절제됩니다.

Approach C

C. Trophy Cabinet

좌측을 큐레이션 쇼케이스처럼 만들고, 우측 그리드를 조금 더 크고 적게 배치하는 방식입니다. 인상적이지만 페이지당 정보량은 줄어듭니다.

추천은 A. Illustrated Folio입니다. 이유는 `ItemBook.png`의 양면 구조를 가장 자연스럽게 살리면서도, 현재의 타일형 블록 자산을 “작은 카드 프레임”으로 흡수하고, 나중에 실제 유물 일러스트 PNG가 들어왔을 때도 좌측 대표 이미지와 우측 썸네일 양쪽 모두에 고급스럽게 확장되기 때문입니다.
