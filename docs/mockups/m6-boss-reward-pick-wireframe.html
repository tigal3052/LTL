선택 확정 버튼

번호 주석

three-way comparison annotations
  1. 세 카드는 같은 시선 우선순위로 놓아 보조 패널 없이도 직접 비교할 수 있어야 한다.
  2. 선택 강조는 카드 자체의 테두리와 상태 변화로만 전달하고, 별도 상세 설명 면은 두지 않는다.
  3. 확정 버튼은 카드 비교가 끝난 뒤 마지막 행동으로 남겨 즉흥 선택보다 비교 후 결정을 유도한다.
