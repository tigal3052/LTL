하단 액션은 한 줄 안에서 좌우 정렬을 맞추고, `전투 시작`이 항상 우측 끝을 차지하도록 구성했습니다. 두 버튼 모두 실제 hover 확대와 press 눌림 연출을 넣었고, 승인되면 이 연출을 공용 버튼 패턴으로 끌어올릴 예정입니다.
프레임 통합

상단의 분리된 헤더 패널을 없애고, 레비아탄 이름과 `런 / 스테이지 / 상점 / 유물 도감 / 설정`을 가장 큰 프레임 안으로 모았습니다.

런 진행 규칙

과거에 클리어한 시작 노드는 회색 기록으로 남기고, 현재 스테이지의 다섯 후보 중 하나만 활성 선택색을 가집니다. 이후 후보는 점선 물음표로 이어집니다.

노드 구분 원칙

미선택 현재 후보와 클리어 이력은 모두 회색 계열로 눌러 시선을 줄이고, 선택된 현재 노드만 원래의 따뜻한 금속 색과 광택을 받도록 설계했습니다.

버튼 패턴

갈색 reset, 붉은 start, hover 시 확대, active 시 눌림, 동일한 높이와 정렬을 하나의 공용 패턴으로 보는 시안입니다.
