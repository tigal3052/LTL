시작 페이지 정리 비교

좌측은 현재 기준 목업, 우측은 이번 요청 1~9번을 반영한 정리안입니다. 텍스트 제거로 생기는 여백을 실제 콘텐츠 면적으로 환원하는 방향이 핵심입니다.

현재안 scaffold text-heavy
요청 반영안 cleaned layout
함께 볼 포인트 review notes

이번 정리안의 핵심

  1. 상단의 `출항 준비 페이지`를 `캐릭터 선택`으로 바꾸고 설명 문단을 제거합니다.
  2. 보드 타이틀과 각 패널 보조 라벨을 걷어내서, 페이지가 더 덜 설명적이고 더 즉시 읽히게 만듭니다.
  3. 우측 상단에 설정 버튼을 고정해 빈 모서리를 기능 영역으로 전환합니다.
  4. 백팩 슬롯은 같은 박스 안에서 더 크게 키우고, hover 시 상세 유물 패널이 붙는 구조로 전환합니다.
  5. CTA는 버튼만 남기고 축소해서 위 패널들이 더 많은 높이를 쓰게 합니다.

9번 유물 선택 영역 제안

  • 추천: 텍스트 제목 없이 색상 카드 2~3개만 먼저 보이고, hover 또는 선택 시 우측 설명 패널이 바뀌는 방식
  • 대안 A: 색상 탭 바 형태로 얇게 줄이고 아래에 상세 카드 1장만 유지
  • 대안 B: 시작 유물 1개만 먼저 고르게 하고, 계열 설명은 툴팁으로 숨겨 밀도를 더 줄이기

지금 화면 밀도에는 첫 번째 방식이 가장 자연스럽습니다. 텍스트 헤더를 지워도 기능이 사라져 보이지 않고, 시작 백팩 hover 패널과도 표현 언어가 맞습니다.
