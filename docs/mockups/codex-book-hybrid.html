우측 카드는 이름과 설명을 제거하고, 썸네일 + 등급 배지만 남겨 시각적 리듬을 크게 가져갑니다. 선택하면 좌측 페이지가 즉시 바뀌고, 긴 목록이 필요할 때는 이 오른쪽 페이지만 독립적으로 스크롤됩니다.
Safe Area 모든 컨트롤은 책 종이 내부보다 한 단계 더 안쪽의 인쇄 안전 영역에만 배치합니다. 제본축, 모서리 장식, 이끼 프레임과 절대 겹치지 않게 여백을 넉넉히 둡니다.
Graphic System 좌측 대표 이미지는 큰 전시 카드, 우측 목록 카드는 기존 `tile` 자산의 작은 블록 질감을 유지한 전용 프레임으로 통일합니다. 선택 상태는 청록 하이라이트, 잠금 상태는 석회색 디밍으로 분리합니다.
Scroll Rule 바깥 책 전체는 고정, 좌우 페이지 내부만 각각 스크롤됩니다. 그래서 배경과 UI가 따로 노는 느낌 없이, 실제 책 페이지 안에서 내용이 움직이는 인상을 유지할 수 있습니다.
