심해 구명병

수치 카드 대신 이 캐릭터가 어떤 분위기의 런을 시작하는지 한 문단으로 읽게 만든다. 구명병은 붉은 계열 시작 유물을 중심으로 출발하며, 같은 색상이더라도 다른 캐릭터는 이름과 효과가 전부 다르게 연결되는 구조를 전제로 한다.

큰 캐릭터 이미지 짧고 굵은 설명 색상 유물로 연결
플레이어는 왼쪽에서 캐릭터를 빠르게 훑고, 가운데에서 출발 정체성을 읽은 뒤, 바로 오른쪽 유물 색상 선택과 출발 버튼으로 이동한다. 텍스트는 보조 역할만 하고, 인상은 큰 이미지와 큰 이름이 먼저 만든다.

캐릭터 전용 색상 유물 선택
붉은 유물

심해 구명병의 기본 출발안. 다른 캐릭터가 같은 붉은 색상을 고르면 이름과 효과는 완전히 달라진다.

푸른 유물

위치 조정과 안정성을 강조하는 대안. 캐릭터마다 색상 의미만 같고 실제 내용은 달라진다.

녹색 유물

연계형 출발안. 상세 수치는 줄이고, 색상과 역할만 빠르게 비교하게 만든다.

황금 유물

리스크가 있지만 강한 출발안. 선택지는 색상 중심으로 읽히고 긴 설명은 뒤로 물린다.

시작 백팩 미리보기 유물이 보일 최소 크기
백팩은 유물 위치가 보일 정도의 최소 크기만 보여주고, 세부 배치는 런 시작 후 정리 화면으로 넘긴다.

시작 CTA

캐릭터와 시작 유물 색상을 고른 뒤 마지막으로 누르는 단계다. 출발 흐름이 오른쪽 컬럼 안에서 자연스럽게 끝나도록 하단에 고정한다.

출발하기

번호 주석

image-first annotations
  1. 왼쪽 캐릭터 선택은 작은 이미지와 이름만 빠르게 훑는 좁은 스크롤 컬럼으로 축소한다.
  2. 왼쪽 컬럼을 줄인 만큼 가운데 선택 캐릭터 확장 패널을 크게 넓혀, 큰 이미지와 큰 이름이 이 페이지의 주인공이 되게 만든다.
  3. 오른쪽은 색상 유물 선택, 최소 크기 백팩, 출발 CTA가 세로 흐름으로 이어진다.
  4. `출발하기` 버튼은 시작 유물과 시작 백팩 하단으로 이동해, 준비와 시작 동선을 한 컬럼 안에서 마무리한다.
