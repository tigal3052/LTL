주석 노트

  1. 캐릭터 비교는 왼쪽에서 이루어지며, 서로 다른 시작 성향을 나란히 살피는 비교 영역이다.
  2. 선택된 결과는 가운데에서 더 큰 영웅 패널로 확장되어 핵심 설명과 시작 방향이 강조된다.
  3. 시작 유물 선택은 바로 오른쪽의 시작 백팩 미리보기에 즉시 영향을 주어 슬롯 구성이 바뀐다.
  4. 이 페이지는 전투 가독성이 아니라 시작 로드아웃 계획을 위한 준비 페이지라는 점을 시각적으로 분명히 해야 한다.
