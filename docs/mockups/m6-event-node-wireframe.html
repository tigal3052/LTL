이벤트 노드 페이지

이 화면은 결과 힌트 보조 패널 없이, 대형 이벤트 이미지와 선택지 패널만으로 사건의 분위기와 결정을 읽게 만드는 단순한 서사 화면이다.

대형 이벤트 이미지 중심 보드 이벤트 장면이 가장 먼저 보이고, 선택지는 아래에서 짧고 분명하게 비교된다.
low-distraction shell
대형 이벤트 이미지
상황 일러스트 / 서사 프롬프트 / 긴장감을 가장 크게 전달하는 메인 장면

선택지 패널

짧은 결과 힌트만 붙이고, 나머지 주의는 전부 장면 이미지에 남긴다.

선택지 A

안전한 대응. 손실은 적지만 얻는 변화도 작다.

선택지 B

위험한 대응. 지금 손실을 감수하고 더 큰 보상을 노린다.

선택지 C

우회하거나 더 읽는 대응. 즉시 결론 대신 상황을 더 파악하는 선택지다.

번호 주석

choice-first annotations
  1. 이벤트 페이지의 첫 시선은 항상 대형 장면 이미지에 머물러야 하며, 보조 패널이 그 시선을 나눠 가지면 안 된다.
  2. 선택지는 짧고 읽기 쉬운 카드로 정리해 비교 부담을 줄이고, 세부 결과 설명은 이 페이지에서 최소화한다.
  3. 도감/상점 같은 외부 행동보다 사건 장면과 결정을 먼저 읽게 만드는 저자극 셸을 유지한다.
