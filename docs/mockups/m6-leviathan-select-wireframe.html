번호 주석

cinematic-hunt annotations
  1. 왼쪽 1/5는 캐릭터 선택과 같은 문법의 좁은 스크롤 목록으로 유지해 단계 전환이 자연스럽게 이어지게 만든다.
  2. 오른쪽 4/5는 거의 전부를 레비아탄 이미지가 차지하고, 상단 런 구조 정보는 숫자와 기호만 남겨 최대한 얇게 처리한다.
  3. `루팅 목표`와 `Looting Start`는 오른쪽 하단에서 이미지 위에 겹쳐져야 하며, 별도 문서 레이아웃처럼 분리되면 안 된다.
  4. 클리어 여부는 목표 카드 위 `CLEAR` 도장으로만 표현해, 상태 정보가 곧 목표물의 이력처럼 읽히게 만든다.
