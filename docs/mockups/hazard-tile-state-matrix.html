Hazard Tile 상태 매트릭스

이번 안은 기존 비교안의 C를 더 정확히 정리한 것입니다. 핵심은 약점 여부는 기본 타일 alpha로, hazard 상태는 hazard 이미지 alpha로 읽히게 만드는 것입니다. hazard 이미지는 기본 타일과 같은 크기로 완전히 겹쳐 그립니다.

해석 기준

  • 약점 없음: 기본 타일이 반투명하게 보입니다.
  • 약점 있음: 기본 타일이 100% 선명하게 보입니다.
  • warning: hazard 이미지가 반투명하게 추가됩니다.
  • active: hazard 이미지가 100%로 올라갑니다.
  • afterglow: active가 끝난 뒤 hazard만 아주 약하게 남았다가 사라집니다.
