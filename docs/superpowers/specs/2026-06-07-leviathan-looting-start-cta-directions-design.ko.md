# Leviathan Looting Start CTA Directions

Date: 2026-06-07
Workspace: LootingTheLeviathan

## Goal

Refine the `leviathan_select` page so the `Looting Start` CTA feels premium on a wide cinematic layout while preserving the edge-to-edge `루팅 목표` panel treatment that previously worked well.

## Constraints

- Keep the current dark leviathan-selection screen as the base context.
- Preserve the old impression that the `루팅 목표` panel sits tightly across the width instead of floating as a small centered card.
- Make the CTA read immediately as the next-step action.
- Explore both premium/luxury and rougher poster-driven directions before picking a final implementation target.

## Research Takeaways

- CTA visibility depends first on contrast, size, and placement rather than any one "best" color.
- Premium/luxury web directions read better when typography looks curated rather than default system UI.
- High-end interfaces often use serif + sans pairings, sentence-case or restrained mixed-case copy, and stronger spacing hierarchy instead of louder decoration.
- Graffiti and poster-inspired directions become more usable when layered lettering stays readable and texture is applied as atmosphere rather than pure distortion.
- Analogue or DIY distress can add character when it softens perfect edges instead of destroying legibility.

## Direction Set

### 1. Refined Cinematic Luxe

- `Gilded Foil Editorial`
- `Ivory Marble Invitation`
- `Velvet Glass Monogram`

This set stays closest to the current leviathan screen. It uses warm gold, ivory, smoked glass, and editorial serif typography to feel expensive without breaking the scene mood.

### 2. High-End Fashion / Industrial Premium

- `Runway Plaque`
- `Titan Alloy Bar`
- `Monument Condensed`

This set pushes further into fashion-brand and industrial-premium territory. It uses condensed display type, metallic or plaque-like surfaces, and broader horizontal rhythm that suits very wide screens.

### 3. Graffiti / Wanted Poster / Street Artifact

- `Neon Tag Relay`
- `Wanted Ledger`
- `Photocopied Riot`

This set adds rougher visual language while still preserving button clarity. It combines layered lettering, stamp logic, taped-paper or xerox textures, and more aggressive framing.

## Preview Structure

The comparison mockup should show all nine options side by side in a 3x3 gallery, and each card should include:

- a miniature leviathan-stage context
- an edge-to-edge `루팅 목표` ribbon treatment
- the CTA style in place
- font pairing notes
- color and finish notes
- a one-line rationale explaining where that direction would work best

## Recommendation Before Selection

Most likely strong finalists:

1. `Gilded Foil Editorial`
2. `Titan Alloy Bar`
3. `Wanted Ledger`

These three provide the clearest spread across premium, premium-industrial, and rough poster energy without losing readability.
